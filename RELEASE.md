# Salon Pro v1.0 release checklist

- Automated integration tests in GitHub Actions
- Admin/staff access controls
- Salon business hours and closure dates
- Partial payments and payment history
- Refund workflow with inventory and loyalty reversal
- Inventory transactions and supplier purchases
- One-tap WhatsApp reminders
- Responsive mobile UI
- Production WSGI/Gunicorn configuration
- Health endpoint
- Environment-based secret and database configuration
- Manual database backup

Production setup still requires the hosting provider to be connected and the production secret/database environment variables to be configured.
